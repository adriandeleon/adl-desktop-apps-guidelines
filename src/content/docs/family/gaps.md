The MUSTs each app still misses, then the SHOULDs open in several apps. Termina's and Mirada's rows were read again
on 2026-11-09, and every app's command ids then too; the rest is from the [feature matrix](../matrix/)'s survey,
with the MUSTs a review of edition 5.0.0 found open and missing here added that day, each read in the app's code at
the commit that edition pins, as were the gaps the decisions on that review opened. A command id, catalog key, chord,
flag, environment variable, property or repository file a rule's statement names is required as spelled; a class,
style or branch name there is Editora's, and an app's equivalent meets the rule
([Coding agents](../../coding-agents/#what-a-rule-looks-like)).

## Missing MUSTs

Three MUSTs are open across the family, so the rows leave them out. No app has the one `Os` class that alone reads
`os.name` ([OS-02](../../same-on-every-os/#os-02)): 51 files read it in Editora, 20 in Termina, 19 in Torrenta, 15 in
Mirada, 4 in nux and 3 in Modula. No app fixes the order of a dialog's buttons
([WIN-11](../../window-shell/#win-11)): none calls `setButtonOrder`, so Editora, Torrenta, Termina, Mirada and nux
draw theirs in JavaFX's order for the OS, and Modula's one dialog has a single button. No app has a UI zoom
([WIN-12](../../window-shell/#win-12)): Editora, Termina and Mirada zoom their content only (the text, the terminal's
font, the image), and Torrenta, Modula and nux have no zoom. So no app's menus follow one either
([MENU-16](../../menus/#menu-16)): Editora's and Mirada's, the two that set the font on `.context-menu`, write 14 px
as a fixed size.

## SHOULDs open in several apps

- **Windows `.msi` signing** ([REL-17](../../release/#rel-17)): no app signs its MSI yet; the certificate isn't
  chosen.
- **Settings Sync** ([SYNC-01](../../templates/settings-sync/#sync-01)): Modula, Mirada and nux don't have it.
- **The Message Log as an in-scene card** ([MLOG-08](../../templates/message-log/#mlog-08)): Termina's is a separate
  window keeping 500 entries, and Torrenta's card is 640 × 300, not 773 × 336.

About window

The About window answers “what exactly am I running?” in one place, and its details are what a bug report needs. Torrenta (AboutDialog), Termina, Modula, Mirada and nux (AboutWindow) follow Editora’s order.

Rules

Section titled “Rules”
  • ABOUT-01 MUST Every app has an About window, reached by Help → About, the help.about command, and on macOS the application menu’s About item.
    • Check (code): help.about is registered and listed in the Help menu, and the macOS application menu’s About item runs it.
    • Reference: Editora ui/AboutDialog.java, ui/MenuBarModel.java (help.about in the Help menu).
  • ABOUT-02 MUST About shows the version and build, the Pauta edition (see below), the runtime, the license, links, and the result of the last update check.
    • Check (code): the window reads the version, build and edition from AppInfo, the same text as --version, and shows the update checker’s last answer.
    • Reference: Editora ui/AboutDialog.java, AppInfo; the Spec table below.
  • ABOUT-03 SHOULD Copy details copies the environment block and leaves the window open; its label becomes “Copied”.
    • Check (code): the button sits in the content, not the dialog’s button bar, so pressing it can’t close the window.
    • Reference: Editora AboutDialog (about.copyDetails, about.copied).
  • ABOUT-04 SHOULD The update status claims nothing before a check has answered: with no answer, or with the check switched off, it says it has not checked, never “up to date”.
    • Check (code): the status falls back to the not-checked text when the checker has no result.
    • Reference: Editora AboutDialog (about.notChecked); the states below.

Pauta edition and conformance

Section titled “Pauta edition and conformance”

About names the edition of these guidelines the app implements and how fully it conforms (Conformance), so a user, a bug report and a reviewer all know which rules the app answers to. No app does it yet; the app template names its edition in its README and AGENTS.md only.

  • ABOUT-05 MUST The edition appears in two places: a link, Built to Pauta 2.0.0, among the others, and a line Pauta: 2.0.0 in the environment block, right after the commit, so Copy details carries it.
    • Check (code): the links use the about.pauta key, and the environment block writes a Pauta: line after the commit.
    • Reference: no app yet.
  • ABOUT-06 MUST The link opens the edition’s own address, https://pauta-project.dev/<edition>/ (for example https://pauta-project.dev/2.0.0/), which never changes, not latest/, which moves on to newer editions.
    • Check (code): the URL is built from the edition number and never contains latest.
    • Reference: no app yet.
  • ABOUT-07 MUST The number is the edition the app meets, not the newest. Moving to a newer edition means reading its changelog for new or stronger MUSTs, meeting them, then changing the number. An app at Partial names the edition it is working toward instead, and says so (ABOUT-09).
    • Check (by hand): audit the app against the MUSTs of the edition it names.
    • Reference: no app yet.
  • ABOUT-08 MUST The edition has one source: a pauta.version property in pom.xml, filtered into build-info.properties and read by AppInfo, like the app’s own version. The README’s Pauta badge and its “Built to” line name the same edition and change with it.
    • Check (code): pom.xml defines pauta.version, build-info.properties carries it, AppInfo reads it, and the README names the same number.
    • Reference: no app yet.
  • ABOUT-09 MUST About shows the app’s conformance, Complete, Core or Partial, as the helper computes it from pauta.json (PAUTA-02) and never higher: a link, Pauta conformance: Core, right after the edition’s, that opens the Pauta window, and a line Pauta conformance: Core (2 exceptions) right after the Pauta: line; with one it says (1 exception), with none (no exceptions). At Partial the edition’s link reads Working toward Pauta 4.2.0: the app does not meet that edition yet, so it does not say it is built to it.
    • Why: Never claim what is not true.
    • Check (code): About calls the conformance helper and holds no conformance name of its own; the link runs help.pauta; at Partial the edition’s link uses about.pautaWorkingToward.
    • Reference: no app yet.

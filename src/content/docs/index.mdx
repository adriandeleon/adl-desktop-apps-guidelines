## How to read it

<span class="lvl lvl-must">MUST</span> is a release blocker for a new app.
<span class="lvl lvl-should">SHOULD</span> is expected unless the app has a stated reason.
<span class="lvl lvl-may">MAY</span> is a pattern worth copying when the app grows into it.

When this guide and Editora disagree, check Editora's code, then fix whichever is wrong.

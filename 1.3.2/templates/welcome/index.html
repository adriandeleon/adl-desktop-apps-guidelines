Welcome page

SHOULD in an app that opens files or projects: the page shown when there is no session to restore, and the answer to “what do I do now?”. An app whose window is its content shows its own empty state instead, with the same ingredients (Torrenta’s drop zone, below). Reference: Editora’s ui/WelcomePane.java, with the text rules in ui/WelcomeText.java and the strings under welcome.*.

  1. 1Identity. The app icon at 64 px beside the name (2.4 em, bold) and the README's one-line tagline, muted. One centered column, at most 640 px wide and never narrower than 340; a longer window scrolls.
  2. 2Start actions, each an existing command: New File, Open File, Open Folder as a Project (only with Projects on), Clone Git Repository (only with Git on), and the Command Palette always last, the gateway to everything else. Accent links with no box; the icon sits in a 26 px column so every label starts at the same x, and the whole row answers a click.
  3. 3Chord, right-aligned past a 32 px gap, in the keyboard color, from the active keymap. Unbound: no chord. Open File shows find-file's chord in the Emacs keymap, where that is the key to learn. The hovered row tints and the chord becomes a chip.
  4. 4Entry number. The first nine recent entries, projects first, are numbered in the keyboard color; typing that digit opens the entry. Projects come in the order of their most recent file.
  5. 5Recent file row. The name keeps its width; a chip names the project (or the host of a remote file); the folder is muted, relative to the project root, with ~ for home, and elides from its start so the part that differs stays visible. The full path is the row's tooltip; right-click offers Copy Path and Remove from recent files.
  6. 6Disclosure. Five rows per list; the rest wait behind "Show N more", which becomes "Show fewer".
  7. 7Customize. The active keymap and app theme by name; each link runs the picker command. Under an Emacs-style keymap a caption explains the notation. On a first run, with nothing recent, this block moves up under Start.
  8. 8Help and footer. Documentation, What's New (the release notes) and the Doctor. Then the version, the home page and the license; a dev build adds its commit on its own line once the lookup, which runs git off the FX thread, has answered.

Behavior

Section titled “Behavior”
  • Shown at startup when there is no session to restore (so always with --no-session), by the view.welcome command (Help → Welcome Page), and when the tab strip is empty after a project swap (showWelcomeIfNoTabs). Standalone diff startup suppresses it while its worker reads the files.
  • Closing the last file tab does not bring it back. The editor area shows its own quiet hint instead: Open File, Open Folder, Command Palette and Welcome Page, each with its chord (EditorEmptyState), and takes focus so chords still reach the window.
  • Rebuilt on every show (refresh), so the recents, the Projects and Git toggles, the keymap and the theme are current. A refresh keeps the focus where it was.
  • Recent lists tell the truth. A file that no longer exists is not offered (RecentFiles.showable, the same filter as the toolbar’s dropdown); remote files are kept unchecked. A project whose root is gone is dropped. Remove from recent files asks first, through the caller, then refreshes.
  • Digits 1 to 9 open the numbered entries: typed characters only, with no modifier, so chords and Enter are untouched (onKeyTyped).
  • Remote Sites appear as their own section when saved SFTP sites exist; a click opens the connection form prefilled.
  • Customize runs keymap.select and theme.setAppTheme; a change made there re-renders the page, chords included.
  • The Welcome tab is not a document: its menu is Close only, no Save, Rename or Pin, and the title bar shows the app or project name, not a file.

In the apps

Section titled “In the apps”

Torrenta has no documents to come back to, so its welcome is an empty state over the table until the first torrent (ui/Welcome.java, bound to the list being empty): a drop zone that says “Drop a .torrent, a magnet or a link anywhere”, the four keys that matter with their chords (open a .torrent file, add what is on the clipboard, filter or run a command, Settings), the clipboard’s magnet or link offered with an Add it button when there is one, and where downloads go with a change link. Nothing on it takes focus: the keys are the way in. Termina, Mirada, Modula and nux open straight into their content and have neither.

Command Palette

MUST in every app. One palette per window, opened by M-x in the Emacs keymaps and Ctrl/Cmd+Shift+P in the others. It lists every registered command, so a command that exists is a command people can find. Reference: Editora’s ui/CommandPalette.java; the pure parts (FuzzyMatch, MatchText, PaletteKeys and the caret-key helper, TextInputKeymap in Editora, TextInputKeys in the copies) are shared with Termina and Mirada. Torrenta shares MatchText and ranks with its own CommandMatcher.

  1. 1Opener chip. The chord that opened the palette, read from the active keymap. No chip when the user has unbound it, never a wrong one.
  2. 2Query field. The first row is the input; there is no title. Prompt "Run command…". Emacs caret keys work inside it.
  3. 3Match highlight. The characters the fuzzy matcher scored, bold in the accent colour. The highlight and the ranking come from the same call, so they never disagree.
  4. 4Selected row. Tinted background plus a 2 px accent bar on its inside edge. The bar is what makes the selection readable in a long list.
  5. 5Key chip. The command's binding in the active keymap, in the keyboard colour (brace periwinkle). Absent when unbound.
  6. 6Unavailable command. Listed, greyed, never selected and inert to clicks. Its tooltip says why and what to do ("Unavailable — no merge, rebase, cherry-pick or revert is in progress.").
  7. 7Description. The selected command's command.<id>.desc, one line with an ellipsis, always one line tall so the card never jumps.
  8. 8Key legend. The palette's own keys, rendered from the active keymap.

Behaviour

Section titled “Behaviour”
  • Open: the palette.show command, from its chord or a menu item. The query starts empty and lists every command.
  • Type to filter; the first enabled match is selected.
  • Move: ↑ ↓, C-n C-p, Page Up/Down. Run: Enter, or a click on an enabled row. The palette closes first, then the command runs.
  • Cancel: Esc, C-g, or a click on the scrim. Focus returns to where it was.
  • Docs: C-h (or the first free chord of C-h, F1, Shift+F1 in the active keymap) opens the selected command’s page on the website, for the running version.
  • A live keymap switch re-renders the chips, the opener and the legend.

Icons and colour

One typeface pair, one palette, one colour vocabulary and one way of drawing icons, so a tab, a status segment, a tree row and a Settings row say the same thing in the same way in every app. Reference: Editora’s styles/ui-font.css and ui/Fonts.java (type), styles/atlantafx-themes/editora-light.css and editora-dark.css (the Caret & Ink palette, which Torrenta and Termina vendor verbatim), the .root block at the top of styles/app.css (the state vocabulary), ui/Themes.java and ui/EditorThemes.java (themes), ui/Icons.java, ui/FileIcons.java, ui/MenuBarIcons.java and editor/MenuIcons.java (icons), and StyleContrastTest, which pins the colour rules.

Type

Section titled “Type”

Inter speaks, JetBrains Mono works. Inter is the chrome: menus, buttons, settings, pickers, status bar. The monospace face is for text that is code or output: the editor, a terminal, the environment block in About, log timestamps.

  • MUST Attach Inter with a scene stylesheet, not a rule in the app stylesheet. Dialogs, the Settings window, the palette, context menus and tooltips each live in a scene of their own that does not share app.css, and a scene sheet is re-applied cleanly when the theme switches at run time (setUserAgentStylesheet). AtlantaFX neither bundles nor names Inter, and JavaFX does not fall through a font-family list, so without the sheet the whole interface renders in the platform’s “System” face.
  • MUST Bundle the font. Do not map the platform’s own UI font (an earlier macOS-only sheet used San Francisco, which JavaFX faux-bolds; Inter has a real bold on every platform).
  • Termina and Torrenta carry the same sheet and the same four Inter faces. Modula is the stated exception: IBM Plex Mono everywhere, because every reading on a radio is a number (see Before adding a setting in Settings).
  • A line of UI text is -color-fg-default; secondary text -color-fg-muted. -color-fg-subtle is about 3:1 and is for disabled or decorative text only (StyleContrastTest.textThatMustBeReadUsesTheMutedRoleNotSubtle).

The palette: Caret & Ink

Section titled “The palette: Caret & Ink”

The flagship theme pair, “Editora Light” and “Editora Dark”, is authored (not vendored) and derived from Editora’s icon: a caret teal accent, ink navy as the text in light and the surface in dark, porcelain and abyss grounds, and brace periwinkle reserved for the keyboard. Amber, red and green are semantic and never decorate.

  • The theme files follow the vendored AtlantaFX community themes: a .root block of -color-* tokens, then component rules that reference only those tokens.
  • SHOULD A new app ships the pair as its default theme. Torrenta and Termina copy editora-light.css and editora-dark.css unchanged into their own styles/; the palette is the family’s, not the editor’s.
  • Brace has no AtlantaFX role, so it is a literal: a ladder() over -color-bg-default that picks a deep ink on a light ground and a lighter periwinkle the darker the ground gets, and reads at 4.5:1 or more on every bundled theme’s default and subtle surfaces (StyleContrastTest.theKeyboardPeriwinkleReadsOnEveryBundledAppTheme).

State colours

Section titled “State colours”

A colour is a meaning, named once on .root and referenced everywhere. The same state wears the same colour in a tab, a status segment, a tree row, a picker and a Settings row.

TokenChains toMeaningWhere it appears
-state-amber-color-warning-fgNot durable yetAn unsaved tab, a read-only file, a narrowed view, a snapshot build
-state-red-color-danger-fgBrokenErrors in the echo area and the Message Log, breakpoints, a recording
-state-green-color-success-fgVerifiedFound, added, passing, running
-state-accent-color-accent-fgThe app is offering somethingAn update, a link, the current branch, a selected row’s bar
-state-olive, -state-violetA ladder of the groundGit only: untracked, renamedThe Project tree and tabs, the Map’s structure columns
-state-keyA ladder of the groundThe keyboard, and nothing elseChord chips, the menu chord column, brace matching
-state-sel-color-accent-subtleThe selected overlay rowThe palette, pickers, the Message Log (about a 13 % accent wash)

Each of the first four also has a -bg (the role’s -subtle) and a -hover (the role’s -muted) variant, so a pill, a row tint and a hover state come from the same place. .state-pill is the shape (bold, radius 999, padding 1 × 8); the colour variant beside it carries the meaning.

  • MUST No fixed hex in a component rule. A hex suits one theme; the roles track every theme for free. A severity or debug colour that is not a state token fails StyleContrastTest.severityAndDebugColoursComeFromTheStateTokens.
  • MUST Readable text uses -color-fg-muted or stronger, which is 4.5:1 on the default, subtle and overlay grounds in both flagship themes. Tinted text (-color-<role>-fg) reaches 4.5:1 on its own subtle fill and on both grounds.
  • MUST Ink on an emphasis fill is -color-fg-emphasis, never white: white on the dark accent is 1.68:1.
  • MUST One focus ring, -focus-ring: -color-accent-emphasis, drawn by the :focus-visible block at the end of app.css, at 3:1 or better on every surface (see Keyboard first).
  • A brand hue the theme has no role for (periwinkle, olive, violet) is a ladder() of -color-bg-default, never a fixed pair: the old fixed light hexes read at 3.2:1 on Editora Dark.
  • SHOULD A pure test reads the stylesheets and does the WCAG arithmetic, as StyleContrastTest does; a contrast regression is invisible in a code diff. Mirada’s AccentTest checks that the accent reads as text on both grounds; Termina’s ThemeTest keeps every chromatic colour of its terminal schemes legible.

Themes

Section titled “Themes”
  • MUST Light and dark, a “follow the system” choice, and a live switch without a restart (see Window shell). The first-run default is Editora Light (Themes.DEFAULT), which is also the fallback for a theme name the app does not know.
  • Editora lists 28 app themes: the Caret & Ink pair, AtlantaFX’s Primer, Nord, Cupertino and Dracula, and 21 community themes (Army, Autumn, Blacky, Blue, Browny, Fall, Navy, News, Spring, Summer, Winter, Yacht, with light and dark variants) vendored unmodified from the MIT-licensed dlsc atlantafx-themes collection. User themes under <config>/themes/ join the list (Themes.names()).
  • Editor themes are separate (EditorThemes). The flagship pair carries its own editor stylesheet; every community theme is served by one adaptive editor theme whose syntax palette is expressed in the theme’s own -color-* tokens, so it follows whatever ground the theme has.
  • Semantic colours never decorate: a theme may change the teal, the ground and the ink, but amber still means “not durable yet”.

Icons

Section titled “Icons”

Every icon is an SVG path drawn in code, coloured by the stylesheet so it follows the theme, and returned as a fresh node per call (a JavaFX node has one parent). There are two families, mid-migration to the UI Kit, and they are not interchangeable.

  • MUST One class per family on a node, never both. A line glyph is coloured by its stroke, and any X .toolbar-icon fill rule (there are dozens) would paint its outline solid. A glyph that moves family moves its CSS with it.
  • MUST The same action wears the same glyph wherever it is reached: Save is one floppy on the toolbar, in the File menu and in a tab’s menu. MenuBarIcons reuses Icons; editor/MenuIcons (the editor package may not depend on ui) copies each twin’s family and path data verbatim.
  • MUST An icon-only control has a name: build it through Icons.button or Icons.toolbarButton, which set the tooltip and the accessible text together (see Keyboard first).
  • SHOULD No invented glyph. A row gets an icon only where an existing glyph genuinely depicts it; a picture that does not mean the thing beside it has to be read and then discounted. The column stays reserved so a menu with a mix stays aligned (see Menus).
  • File icons (FileIcons): a pure iconKeyFor(name) resolves a file name to a key (unit-tested without the toolkit), forFileName turns the key into a node. Brand logos from Simple Icons, category glyphs (image, archive, PDF, table, lock, JSON, settings) from Material, and the generic document glyph for anything unknown, so a new type never regresses the look.
  • Licences. Every glyph set and font is credited in NOTICE: Material Design Icons (Apache-2.0), Simple Icons (CC0; the logos stay their owners’ trademarks), Octicons and Seti UI (MIT), Inter and the monospace faces (OFL).

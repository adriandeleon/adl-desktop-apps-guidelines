Repository documents

Start from the template. adl-desktop-app-template carries an example of every file on this page, filled in for a placeholder app, ExampleApp. scripts/rename.sh <AppName> <package> renames it to yours.

FileWhat it holdsLevel
README.mdA landing page, about 200 lines: logo, badges, one-paragraph pitch, hero screenshot, highlights, install, build, command line, config folder, license. Detail lives on the website.MUST
CHANGELOG.mdKeep a Changelog 1.1 + SemVer. An ## [Unreleased] section with Added / Changed / Fixed / Removed; each entry opens with a bold one-line summary written for users.MUST
LICENSEMIT, “Copyright (c) 2026 Adrián Arturo De León Saldivar”.MUST
NOTICEApp name, copyright, “licensed under the MIT License”, then every bundled third-party component with its license (Inter is OFL, AtlantaFX is MIT, OpenJFX is GPLv2+CPE…). Ship it inside the installers too.MUST
AGENTS.md (+ a one-line CLAUDE.md pointing to it)Operational rules for coding agents: essential commands, worktree-per-task, change checklist. Not a changelog.MUST
CONTRIBUTING.mdHow to build, test, format, and open a PR.MUST
docs/architecture.md, conventions.md, testing.md, gotchas.md, release.md, building-and-packaging.md, decisions/ (ADRs).MUST
TODO.mdThe open list, kept in the same PR as the change.MAY
.github/ISSUE_TEMPLATE/bug_report.ymlIssue form whose field ids (environment, report) the in-app Report a Problem fills.MUST
branding/Source SVG of the icon; generated PNG/ICNS/ICO live in packaging/.MUST

Section titled “README badges (in this order)”

The hero screenshot is a <picture> with a dark srcset under prefers-color-scheme: dark, so GitHub shows the screenshot that matches the reader’s theme. Screenshots are taken at 2× by a headless harness so they can be retaken after any UI change. The README states that the app is built with the help of AI coding tools.
